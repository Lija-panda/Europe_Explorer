# 🌍 Europe Explorer – The Continent of Wonders

An interactive and informative website that explores the beautiful continent of Europe, its countries, cultures, famous personalities, movies, and tourist attractions.

## 📌 About the Project

**Europe Explorer** is a front-end web development project created using HTML, CSS, and JavaScript. It provides users with an easy and engaging way to discover interesting information about selected European countries through dedicated country pages.

## ✨ Features

- 🗺️ **Explore European Countries:** Discover France, Germany, Italy, and Spain.
- 🏛️ **Tourist Attractions:** Learn about famous places and landmarks.
- 💱 **Country Information:** Explore capitals, currencies, and other country details.
- 🎬 **Movies and Personalities:** Discover notable movies and famous personalities associated with the countries.
- 🔐 **Login and Signup Interface:** Front-end authentication interface with simulated session handling.
- 📱 **Responsive Design:** Designed to provide a user-friendly browsing experience across different screen sizes.
- 🎨 **Interactive UI:** Includes animations, toast notifications, and Font Awesome icons.
- ℹ️ **About Page:** Learn more about the purpose of the project.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layouts, animations, and responsive design
- **JavaScript** – Interactive functionality and client-side session handling
- **Font Awesome** – Icons

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the website and navigate between the country pages.

You can also use the **Live Server** extension in Visual Studio Code for local development.

## 🔐 Authentication Note

The login and signup interface is implemented on the front end. It uses simulated authentication/session handling and does not provide real server-side authentication or database storage.

## 🎯 Project Objective

The main objective of Europe Explorer is to demonstrate front-end web development skills while presenting useful information about European countries through an attractive, interactive, and easy-to-navigate website.
